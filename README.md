## 📌 Overview

**The Casawood** is a specialized furniture e-commerce platform designed to bring an immersive, bespoke showroom experience directly to the browser. It features a custom **Fabric & Color Selection Engine** that allows shoppers to preview high-end upholstery materials (e.g. KEIBA, MERRY, VELVETO, ABOONE) and customized color palettes in real time before purchasing.

---

## ✨ Features

- 🎨 **Fabric & Color Engine:** Dynamic 36px interactive swatch selector with smooth visual feedback and state management.
- 🛍️ **E-Commerce Workflows:** Product catalogs, responsive cart, filtering, and checkout flows.
- 📱 **Responsive UI:** Tailored for seamless mobile and desktop furniture browsing.
